# Single Doctor Portfolio Website

A premium, high-conversion portfolio website for a psychiatrist / psychologist / therapist.

## Features

- **Top contact bar** with phone, WhatsApp, email, and hours — always visible
- **Premium hero** with credentials card and floating trust indicators
- **Smooth reveal animations** on scroll
- **FAQ accordion**
- **Booking form** with validation
- **Floating WhatsApp button**
- **Testimonials section** with review summary
- **Credentials section** (education, registrations, experience)
- **Specialties grid** with icons
- **Mobile responsive** design
- **SEO ready** (schema.org Physician markup)

## Customize

1. Replace the doctor name, credentials, and specialties in `index.html`
2. Update phone number, email, and WhatsApp number everywhere
3. Replace the `.photo-placeholder` with a real `<img>` tag when you have a photo:
   ```html
   <img src="photo.jpg" alt="Dr. Ayesha Khan" class="photo-placeholder">
